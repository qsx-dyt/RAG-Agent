# 报销制度

## 差旅费报销
员工出差发生的差旅费,须在出差归来后 7 个工作日内提交报销申请。
报销差旅费需要提供以下材料:正规发票、行程单(机票/火车票)、出差审批单。
住宿费标准:一线城市每晚不超过 500 元,其他城市每晚不超过 350 元,超出部分不予报销。
市内交通费按实报销,需保留票据;出租车票须注明起止地点和事由。

## 审批流程
差旅费报销审批流程:员工提交报销单 -> 直属上级审批 -> 财务部审核 -> 财务总监签字 -> 出纳付款。
直属上级审批时限为 3 个工作日,财务部审核时限为 5 个工作日。
金额超过 2000 元的报销单需额外经过部门总监审批。
报销款项通过银行转账发放,通常在审批完成后 5 个工作日内到账。

## 其他报销
办公用品、培训费、招待费分别适用对应的报销规定,均需保留合规票据。
